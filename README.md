¿Qué es y qué hace la práctica? / ¿Qué aprendimos?
La práctica consistió en crear un detector de spam básico y construir una interfaz sencilla con Tkinter para probarlo.
Aprendimos a usar Git y GitHub, crear un proyecto desde cero y combinar la lógica del programa con una interfaz gráfica.

¿Cómo lo hicimos? / Tecnologías–Librerías utilizadas
	1.	Configuramos el entorno virtual e instalamos las librerías necesarias.
	2.	Usamos Git para controlar versiones y GitHub para subir el repositorio.
	3.	Programamos un detector simple y creamos la interfaz con Tkinter.

Tecnologías: Python, Tkinter, Git y GitHub y lo incluido en requirements.txt
